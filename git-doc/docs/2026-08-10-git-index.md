# Git — my first file index

> How I catalogued every file in the Git learning folder and built a coverage table.

## What I did

I wanted to see exactly what I'd built in the `git/` folder, so I listed every file, grouped them by type, and built a coverage table. The goal was to spot gaps and make sure key files were easy to find.

## Steps

1. **Listed every file.** I ran `find git -type f` from the repo root. That gave me 20 files across notes, scripts, docs, and hooks.
2. **Grouped by category.** I sorted them into notes, scripts, docs, snippets, and hooks. Snippets turned out to be empty for Git, which was a useful finding.
3. **Built the coverage table.** I counted files per category to see where I have depth and where I'm thin.
4. **Linked the key files.** I added direct links to `semantic-release-automation.sh` and the two companion quickstart notes that the task asked about.
